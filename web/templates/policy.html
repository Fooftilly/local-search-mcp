Import or export domain rules

Portable domain rules (issue #13)

Export active explicit allow/deny rules (JSON v1). Only domain, decision, scope and UTC expiry are included. Pending requests, single-use grants, history, machine paths and credentials are excluded.

Imports are atomic, add only missing decisions, and reject conflicting explicit rules. Existing rules, expired grants or a stale preview cannot be silently overwritten. Preview never changes your database. A local confirmation is required before applying.
