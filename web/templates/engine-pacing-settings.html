Per-engine search pacing

${alert}

Disabled by default. When enabled, only one explicitly selected, policy-listed engine can be searched. Default fanout, categories and bang shortcuts are rejected. The bridge applies the interval before the next search without restart. Existing in-flight searches are not interrupted.

Intervals: 0–3600 seconds. Up to 64 unique non-Google engine names. Enabling requires a live, owner-verified SearXNG inventory. No service is started or restarted. Saving a disabled policy works while SearXNG is sleeping.

Each private engine admission holds a cross-process lock over one search attempt. This form does not set upstream provider quotas, change search engine flags or authorize a crawl. Invalid or unsafe stored state must be repaired manually; the editor will not overwrite it.
